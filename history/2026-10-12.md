初始化"薄肌健康"纯前端 PWA 项目（~/Documents/code/health-pwa/）。

## 关键决策

1. **零依赖架构**：全部纯 HTML + CSS + 原生 JS，不接后端、不接API、不用npm。唯一外部资源是 week.html 的 Chart.js CDN（离线时优雅降级为文字提示）。
2. **数据存储**：全部 localStorage。键设计：`bm_profile`（档案+计算结果）、`bm_records`（按日期 YYYY-MM-DD 存每日记录）、`bm_settings`（设置）。照片经 canvas 压缩（800px、JPEG 0.7）后 base64 入库，导出 MD 时省略照片以控制文件体积。
3. **AI 策略**："不接API"的替代方案是**拼装提问文本 + 一键复制**，让用户粘贴给自己手机里已有的任意AI（元宝/Kimi/智谱/ChatGPT）。提问模板放 `data/prompts/`，模板中明确要求AI"不做医疗诊断、不承诺效果"。
4. **公式口径**：BMR 用 Mifflin-St Jeor；减脂摄入 = TDEE − 400（300~500取中值），下限 BMR；预计减脂 = 缺口 × 0.13 g/kcal。
5. **连胜定义**：连续饮水达标天数；今天未达标不打断（从昨天往前数），避免用户晚上打开就"断了"的挫败感。
6. **睡眠趋势图**：sleep.html 的7天小图用手绘 SVG（无依赖、可离线）；week.html 的正式趋势图用 Chart.js。
7. **提醒限制**：纯前端没有推送服务器，喝水提醒用 Notification API + setInterval，仅页面打开时生效——已在 UI 中如实说明，不夸大。
8. **红线**：不执行 rm / git push / 全局 pip；文案禁写"保证瘦/治疗/治愈"等医疗承诺；sell/README.md 中列了卖家话术红线。
9. **主题**：薄肌深色配色 深灰 #1a1a2e + 卡片 #16213e + 青绿 #00d4aa + 文字 #e0e0e0，手机优先响应式，底部 TabBar。
10. **商业化**：2元一次性买断（sell/README.md 含买家教程 + 卖家话术 + 免责），无订阅无内购。
