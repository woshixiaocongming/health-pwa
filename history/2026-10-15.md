# 2026-10-15 决策记录

## v1.13：移除兑换码验证，改为完全免费本地版

1. **动机**：不再做防盗用/收费门槛，产品定位回到"纯本地免费记录工具"，减少一层入口拦截与心智负担。
2. **删除文件**：js/license.js（码表 CODE_TABLE 101 条 + verifyCode 校验 + 设备名额逻辑 + 全屏激活遮罩 DOM 构建）、gen-codes.js（批量生成兑换码脚本）、codes-backup.txt（100 个可用码明文备份，留着会直接泄露码表）。
3. **删除引用与样式**：9 个页面 head 里的 `<script src="js/license.js"></script>`；css/style.css 的 `.license-mask/.license-card/.license-input/.license-btn/.license-err/.license-note` 整块；sw.js ASSETS 里的 `./js/license.js`。SW 更新提示（.sw-update-btn、TAKE_OVER 消息、app.js 新版本浮标）与兑换码无关，全部保留。
4. **路径审查结论**：全站资源引用本来就是相对路径（`manifest.webmanifest`、`css/style.css`、`js/*.js`、`icons/*.png`、`data/prompts/*.txt`；CSS 里唯一 url() 是内联 SVG data URI；week.html 的 Chart.js 是 https CDN 绝对 URL，不能改）。没有任何以 `/` 开头的绝对路径需要转换；唯一的绝对路径 `/api/verify` 只出现在被删的 license.js 注释里。
5. **缓存**：CACHE_NAME v13 → v14，激活时强清旧缓存，老用户刷新后自动拿到无门槛版本；残留的 boji_license / boji_device_id / boji_code_devices localStorage 键不再被读取，无副作用。
6. **自查**：本地 no-store 服务打开 index.html，无遮罩、无兑换码提示；首页表盘/大水/饮食/运动/睡眠/复盘/设置/数据管理逐页可用；图标、样式、各 JS 均 200 加载；控制台零报错。
